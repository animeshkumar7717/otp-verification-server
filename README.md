# OTP Verification Backend (Node.js + Express + MongoDB)

This backend handles phone number OTP verification using 2Factor SMS API.

## Features
- Send OTP via SMS (2Factor API)
- Verify OTP with expiry
- Store user data in MongoDB
- JWT token on successful verification

## Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose
- Axios
- dotenv
- jsonwebtoken
